Journey Planner acceptance criteria

- Main navigation and the journey page title display “Journey Planner”.
- The four stage cards form two columns and two rows on mobile and desktop.
- Narrow-screen cards wrap their text within their column.
- Existing checklist links, coming-soon states and saved progress continue to work.

Validation: npm run check and npm test. Browser layout checks are not included in those commands.

Aotearoa topic cards acceptance criteria

- All six home-page introduction cards remain in a two-column grid on mobile.
- Each topic displays a matching icon: globe, people, weather, heart, shield or graduation cap.
- Topic labels wrap inside their cards and existing destinations remain available.
- The Explore page uses the same topic icon mapping.
