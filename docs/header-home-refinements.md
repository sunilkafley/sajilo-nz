# Header and homepage refinements

Acceptance criteria:
- Navigation presents Home, Explore, Journey Planner and FAQs in that order on mobile and desktop; existing destinations and active states remain functional.
- The home money card reads Living Expenses and still opens the existing money topic.
- Language controls display a Nepal flag when offering Nepali and a New Zealand flag when offering English. Decorative SVGs retain the existing accessible button names and route context.
- The hero description has an opaque mint background with dark text so the landscape does not obscure it.
- Reduced header padding retains 44px control targets, clear spacing, the NZ clock, and the existing mobile requirement that six topic cards fit above navigation.

Verification uses existing unit tests and the browser header/home-topic/branding suites. Real-device Safari remains a separate manual check.
